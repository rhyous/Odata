# Rhyous.Odata

A library to aid in meeting the OData specification.

## Features

- OData object models and serialization
- Related entity handling and conversion
- Entity relationship mapping
- Support for OData URI parsing and building
- Sorting and filtering capabilities

## Installation

```bash
dotnet add package Rhyous.Odata
```

## Usage

This package provides core OData functionality including:

- `OdataObject<TEntity, TId>` - Main OData object wrapper
- `OdataObjectCollection<TEntity, TId>` - Collection of OData objects
- Related entity attributes and converters
- Entity relationship mapping

## Related Packages

- **Rhyous.Odata.Csdl** - CSDL (Common Schema Definition Language) format support
- **Rhyous.Odata.Expand** - OData $expand query option support
- **Rhyous.Odata.Filter** - OData $filter query option support
