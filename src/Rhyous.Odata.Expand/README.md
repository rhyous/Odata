# Rhyous.Odata.Expand

A library to aid in meeting the OData specification for the `$expand` query option.

## Features

- OData $expand query parsing
- Expand path evaluation
- Attribute-based expand configuration
- Support for nested expand paths

## Installation

```bash
dotnet add package Rhyous.Odata.Expand
```

## Usage

This package provides support for the OData `$expand` query option, allowing you to:

- Parse `$expand` query strings
- Evaluate expand paths
- Configure expand behavior using attributes
- Handle nested entity expansion

## Dependencies

- **Rhyous.Odata** - Core OData library
