# Rhyous.Odata.Csdl

A library to aid in providing CSDL (Common Schema Definition Language) format for a given type.

## Features

- CSDL document generation
- Entity type and property metadata
- Navigation property support
- Schema builder and formatters

## Installation

```bash
dotnet add package Rhyous.Odata.Csdl
```

## Usage

This package provides CSDL generation capabilities for OData services, allowing you to:

- Generate CSDL metadata documents
- Define entity types and their properties
- Configure navigation properties
- Build complete OData service metadata

## Dependencies

- **Rhyous.Odata** - Core OData library
